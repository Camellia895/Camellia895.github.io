而钱对她来说无比重要,或者说是“为数不多的价值”的一部分，问题的权重略低于心理。

她有给我发过一张人设，说这图上的人设是照着自己的想象刻画的，或者是这就是她的人设。从后续的描述来看，魔法为真，想象力挺好的，性格也为真，样貌是自己想象的。

从聊天记录来看，猫猫骑士团本身也是她想象的一部分，弥足珍贵。价值感当然也衍射到这个mod上了，所以聊到这个东西的时候时常会参杂一些奇怪的东西。


她的价值感很薄弱。她想要去寻求某种价值，某种肯定。她过去时候大概被否定了很多很多次才变成这样的，否定的来源可能是具体的人也可能是周遭的环境。
这需要暴露记忆，或者认知行为疗法的帮助。但是这需要她真的愿意去改变。
前者要求一个足够安全的环境去回忆过去。

原话”我只想安安心心的，把自己当成最完美的自己“

她需要人去关心她，但是过低的价值感让她不能很好地去接纳别人的关心，。

她在寻求独立？独立似乎并不现实，是想象的独立。

人是会改变的。我秉承着这样的观点。看到人本身远比看到事情发展重要。
